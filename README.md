# cursor-github-mvp

Минимальный MVP на Node.js: HTTP-сервер на встроенном модуле `http`.

Сервер слушает порт **3000** и отвечает текстом `Hello, MVP!`.

## Требования

- [Node.js](https://nodejs.org/)

## Запуск

В корне проекта:

```bash
node src/index.js
```

или:

```bash
npm start
```

Откройте http://localhost:3000 или выполните:

```bash
curl http://localhost:3000
```

Остановка сервера: `Ctrl+C`.
